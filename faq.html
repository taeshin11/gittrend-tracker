Frequently Asked Questions

What is GitTrend Tracker?

GitTrend Tracker is a free dashboard that shows you the most popular GitHub repositories that are trending right now. It uses the GitHub API to find repos gaining the most stars.

How do I filter by programming language?

Click on any language tab at the top of the dashboard (Python, JavaScript, TypeScript, Rust, Go, etc.) to see trending repos only in that language. Click "All" to see all languages.

What do Daily, Weekly, and Monthly mean?

These time ranges control how far back the dashboard looks for trending activity. "Daily" shows repos with recent pushes in the last 24 hours, "Weekly" looks at the past 7 days, and "Monthly" covers the last 30 days.

How often is the data updated?

Data is fetched from the GitHub API in real time. Results are cached locally for performance: daily data for 30 minutes, weekly data for 1 hour, and monthly data for 2 hours.

Why do I see a rate limit warning?

GitHub limits the number of API requests. If you see a rate limit warning, cached data is being shown. Wait a few minutes and refresh, or the cache will automatically update.

Is GitTrend Tracker free?

Yes, GitTrend Tracker is completely free to use. There are no accounts, subscriptions, or hidden fees.

What do the sparklines show?

The small line charts on each card represent the approximate star growth trend of the repository, helping you visualize whether a repo is steadily gaining popularity.

Can I change the language of the interface?

Yes! Use the language dropdown in the top right corner to switch between English, Korean, Japanese, Chinese, Spanish, French, German, and Portuguese. The interface auto-detects your browser language on first visit.
